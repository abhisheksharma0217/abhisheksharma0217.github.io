## Section colors — Fabio Crameri's batlow

The navigation uses five 8-bit sRGB samples from **batlow**, a Scientific Colour Map by Fabio Crameri, rounded from its 256-row data table:

| Section | Index | Color |
| --- | ---: | --- |
| Overview | 0 | `#011959` |
| Work | 64 | `#226061` |
| Experience | 112 | `#677b3e` |
| Publications | 160 | `#c09036` |
| Contact | 208 | `#fca993` |

Sources: [Scientific Colour Maps](https://www.fabiocrameri.ch/colourmaps/), [archived collection](https://doi.org/10.5281/zenodo.1243862), and the [batlow table distributed with cmcrameri](https://github.com/callumrollo/cmcrameri/blob/master/cmcrameri/cmaps/batlow.txt). The complete map dataset and cmcrameri software are not bundled.
